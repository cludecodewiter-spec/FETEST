# 基数変換クイズ

基本情報技術者試験で頻出の「基数変換・2の補数表現」を練習できる、スマホ向けのオフライン一問一答クイズです。

## 特徴

- **オフラインで動作**：`index.html` 1ファイルだけで完結しています。外部サーバーへの通信は一切行いません。インターネットに繋がっていないスマホ・PCでも、このファイルをブラウザで開くだけで遊べます。
- **スマホ向けデザイン**：タップしやすい大きめのボタン、ダークモード自動対応、ノッチ付き端末向けのセーフエリア対応など、スマホでの利用を想定したUIです。
- **11の出題範囲**（すべて基本情報技術者試験の頻出パターンに基づく）
  - 10進数 ⇔ 2進数
  - 10進数 ⇔ 16進数
  - 2進数 ⇔ 16進数
  - 10進数 ⇔ 8進数
  - 小数の基数変換（10進小数 ⇔ 2進小数）
  - 2の補数表現（正の数の10進数 → 負の数の2進数表現、およびその逆）
- 出題範囲・問題数（5/10/15/20問）を選んで開始
- 4択（ア・イ・ウ・エ）形式。回答するとすぐに正誤と、実際の数値を使ったステップバイステップの解説が表示されます
- 学習記録（実施回数・正答率・分野別正答率）を端末内（localStorage）に保存し、次回起動時にも表示されます
- 問題はすべてその場でランダム生成されるため、何度解いても新しい問題に出会えます

## 使い方

### そのまま開く（一番簡単）

1. `index.html` をスマホに転送します（メール添付、AirDrop、クラウドストレージ経由のダウンロードなど、方法は問いません）。
2. スマホのファイルアプリやブラウザから `index.html` を開きます。
3. あとは機内モードでも使えます。

### パソコンから確認する場合

`index.html` をダブルクリックしてブラウザで開くだけで動作します。

### Webサーバーで公開する場合（任意）

GitHub Pages などにこのリポジトリをデプロイすれば、URLでアクセスできるようになります（初回アクセス時のみ通信が必要で、それ以降はページ自体はキャッシュされます）。

## 出題内容について

出題パターンは、基本情報技術者試験の過去問・対策資料で頻出とされる以下の傾向を参考にしています。

- 2進数・8進数・16進数と10進数の相互変換（重み計算、割り算による変換）
- 2進数と16進数の相互変換（4桁区切りによるグルーピング）
- 10進数の分数・小数を2進数の小数に変換する問題（例：「10進数の0.75を2進数で表すと」）
- 2の補数を用いた負の数の表現（8ビットでの表現、反転+1の手順）

## 技術的なメモ

- Vanilla HTML/CSS/JavaScript のみ。フレームワーク・外部ライブラリ・CDN依存なし
- 出題ロジックは自動テスト済み（各出題範囲55,000問以上を生成し、選択肢の重複や解答不整合がないことを確認）
